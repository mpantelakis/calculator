# Calculator

A lightweight calculator built with vanilla HTML, CSS, and JavaScript as part of [The Odin Project](https://www.theodinproject.com/) Foundations curriculum.

**<a href="https://mpantelakis.github.io/calculator/" target="_blank" rel="noopener noreferrer">Try the live demo</a>**

![Calculator preview](assets/calculator.png)

## Features

- Addition, subtraction, multiplication, and division
- Decimal number input
- Clear and delete controls
- Chained calculations
- Results rounded to two decimal places
- Division-by-zero protection

## Built With

- HTML5
- CSS3 and Flexbox
- Vanilla JavaScript

## Run Locally

No build tools or dependencies are required.

1. Clone the repository:

	```bash
	git clone https://github.com/mpantelakis/calculator.git
	```

2. Open `index.html` in a browser.

Alternatively, serve the project with any local static file server.
